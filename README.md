# Crisis Lines — privacy policy

One static page. It exists because Google Play requires every Android app to publish a
privacy policy at a public URL, and their reviewer opens it once.

It is **not** part of the app. Nobody using Crisis Lines ever sees this page: it is not a
screen, not a tab, and not linked from inside the app. The app's directory of services
ships inside the app bundle and works with no network at all.

The app source is private. This page is the only public part.

Served at <https://cosmo4u1.github.io/crisis-lines-privacy/>.
